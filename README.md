# 客製化加價小幫手

2026/10/12 起客製化服務收費的問答機器人。顧客用聊天的方式提問，常見問題直接依收費規則回答，比對不到的才交給 OpenRouter 免費模型；顧客看不懂時，會在收費圖表上用橘色螢光筆標出重點並回傳圖片。

## 運作方式

0. **少冰／去冰反問補不補**（門市回饋）：只說少冰／去冰不算錢，並立刻反問「需要補牛奶嗎？」（茶類問「需要補茶嗎？」）。橘框裡有「要補／不補」按鈕，在同一張卡片切換價格。沒提到冰量的冰飲，卡片上有「正常冰／少冰／去冰」按鈕，點少冰／去冰就會出現橘框。冷萃類飲品不能補。
   **不含濃縮咖啡的飲品**（抹茶那堤、茶那堤、巧克力、星冰樂、冷萃等）：加一份一般濃縮 +$15；加特選濃縮＝加濃縮 +$15＋特選豆 +$15，共 +$30。
   含「特選」的飲品：官網價格仍是舊的特選升級 +$10，10/12 新制改為 +$15，`drinks.js` 已各加 $5。
1. **模糊比對飲品名稱**：用整段文字和全部飲品名稱比相似度（相同的連續字越多越像），自動選最像的一杯，可容忍錯字、漏字（例如「焦糖馬奇朵」「巧克力碎片星冰樂」）。「加／換／升級／補」後面的字視為加料，不會被當成飲品；單獨說加料（例如「可可碎片要加錢嗎」）也不會。模糊判斷時卡片會顯示「依『…』判斷是這杯」，並提供其他相似飲品一鍵改選；幾杯一樣像時列出選項讓人點。只打部分名稱（例如「可可」「桂花」「星冰樂」）會列出所有符合的飲品；用別稱（例如「巧克力」「美式」）時自動選最像的一杯，並在「不是這杯？」列出其他名稱相近的飲品。打完整品名則不顯示候選。
2. **認得飲品**：打飲品名稱（含「拿鐵」「純濃抹茶」「粉紅飲」這類常見說法），會先標出這杯「含奶／不含奶」、組成和各杯型價格。少冰／去冰時，含奶的提示「補奶類」、不含奶的提示「補飲料」，並算出含飲品的總價。

1. **關鍵字優先**：問題先在瀏覽器裡比對 `public/kb.js` 的規則，命中就立刻回答，不耗用 AI 額度。
2. **加價試算**：一次提到兩項以上（例如「燕麥奶＋抹茶液＋環保杯」）會列出每項加價與合計。
   - 自備環保杯一律折 $10，**買一送一時不折**。
   - 風味糖漿、其他配料、高蛋白雲朵每杯每項限一份（例如「8 份抹茶」會以 1 份計並提醒）。
   - 濃縮咖啡按份計價（加兩份 = +$30）。
3. **AI 補位**：關鍵字比對不到時，呼叫 `/api/chat`（Cloudflare Pages Function），由 OpenRouter 免費模型依同一份規則回答。
4. **螢光筆標圖**：顧客說「看不懂」「什麼意思」「標給我看」，或點「看不懂，標給我看」，就把上一題相關的項目畫上橘色螢光筆，回傳標示後的圖片（泡泡裡顯示標示處放大，點開可切換整張圖、下載）。環保杯、買一送一不在圖表上，就只用文字說明。

## 檔案結構

```
public/              ← 網站本體（Cloudflare Pages 的輸出目錄）
  index.html         聊天介面
  style.css
  app.js             介面邏輯
  engine.js          關鍵字比對、試算、看不懂偵測
  kb.js              ★ 收費規則、回答內容、圖上標示位置、AI 規則說明（改規則只要改這裡）
  drinks.js          ★ 飲品資料：含奶類型、組成、價格（2026/10/12 讀取自星巴克官網飲品頁）
  highlight.js       在圖上畫螢光筆
  menu.jpg           收費圖表
  _headers           安全性與快取標頭
functions/api/chat.js  ← 串接 OpenRouter 的後端（API 金鑰只在這裡讀取）
tests/engine.test.mjs  ← 規則測試（npm test）
```

## 部署到 GitHub Pages（不含 AI）

`gh-pages` 分支就是 `public/` 的內容，推上去後網址為 `https://<帳號>.github.io/<repo 名稱>/`。
GitHub Pages 只能放靜態檔案，無法保管 API 金鑰，所以在 `github.io` 上 AI 補位會自動關閉，其餘功能（關鍵字問答、加價試算、螢光筆標圖）照常運作。
若之後要開啟 AI，把同一個 repo 接到 Cloudflare Pages（見下一節）即可。

更新網站（先加版本號，避免手機抓到舊快取）：

```bash
node scripts/stamp-version.mjs
git add -A && git commit -m "更新"
git branch -f gh-pages $(git subtree split --prefix public)
git push origin main && git push -f origin gh-pages
```

## 部署到 Cloudflare Pages（含 AI）

`wrangler.toml` 已設定好輸出目錄 `public` 和 Workers AI 綁定，連結 GitHub 後會自動套用。

1. Cloudflare 後台 → Workers & Pages → 建立 → Pages → 匯入 Git 存放庫，選 `custom-fee-assistant`。
2. 框架預設選「無」，建置指令留空，按「儲存並部署」。
3. 部署完成後打開 `https://<專案>.pages.dev/api/chat`，看到 `"providers":["workers-ai"]` 就代表 AI 已接上。

之後推送到 `main`，Cloudflare 會自動重新部署。

### AI 怎麼用

- 規則看得懂的問題（大部分點單與收費問題）在瀏覽器直接回答，不呼叫 AI、不花額度。
- 規則答不了、或點單裡有看不懂的詞時，才交給 AI。
- AI 遇到點單時只負責「聽懂」，把口語改寫成標準點單（例如「大杯冰的抹茶拿鐵冰塊少一點加一份咖啡」→「冰醇濃抹茶那堤 大杯 少冰 加一份濃縮」），金額一律由收費規則計算，卡片會標示「AI 判讀為：…」。

### AI 供應商（依序嘗試，前一個失敗才換下一個）

| 順序 | 供應商 | 設定 | 說明 |
| --- | --- | --- | --- |
| 1 | Cloudflare Workers AI | `wrangler.toml` 的 `[ai]`，免金鑰 | 每天 10,000 Neurons 免費；預設模型 `@cf/qwen/qwen3-30b-a3b-fp8` |
| 2 | Google Gemini | 祕密 `GEMINI_API_KEY`（選填） | 免費層模型如 `gemini-3.5-flash-lite`，額度以 AI Studio 顯示為準；免費層資料會被用於改進產品 |
| 3 | OpenRouter | 祕密 `OPENROUTER_API_KEY`（選填） | 目前免費模型很少，每天 50 次（儲值 10 美元後 1,000 次） |

換模型：改 `wrangler.toml` 的 `WORKERS_AI_MODEL` 後推送。可用模型與價格見 Cloudflare Workers AI 的定價頁。

### 用量與費用

- Workers Free 方案：每天 10,000 Neurons 用完就停（AI 補位暫停，規則回答照常），不會產生費用。
- 改用 Workers Paid（每月 5 美元）：超過免費額度後每 1,000 Neurons 0.011 美元。
- 大量推廣時，建議在 Cloudflare WAF 為 `/api/chat` 設定速率限制（例如每個 IP 每分鐘 10 次）。

## 修改內容

- **收費或回答文字**：改 `public/kb.js` 的 `TOPICS`（問答）與 `ITEMS`（試算價格、辨識用詞），以及最下方 `buildSystemPrompt()`（AI 依據的規則）。
- **環保杯折抵金額**：`ECO_CUP_DISCOUNT`。
- **飲品、價格、含奶與否**：改 `public/drinks.js`；常見說法加在 `DRINK_ALIASES`。官網「客製化調整」頁目前仍是舊價格（例如特選濃縮 +$10），小幫手以 10/12 新制圖表為準。
- **更換圖表**：替換 `public/menu.jpg`，並更新 `IMAGE` 的寬高與 `REGIONS` 裡每個項目的位置 `[x, y, 寬, 高]`（原圖像素）。
- 改完執行 `npm test` 確認試算與標示沒有壞掉。


## 建議

- 綁定自訂網域後，可在 Cloudflare WAF 為 `/api/chat` 加一條速率限制（例如每個 IP 每分鐘 10 次），避免免費額度被少數人用光。
- 頁面底部已註明「實際金額以門市結帳為準」；收費規則若有更新，記得同步修改 `kb.js` 與圖表。
